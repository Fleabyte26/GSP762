# GSP762 – Build a Serverless App that Creates PDF Files (Pet Theory)

## Known lab traps (read first)

1. The lab's commands use dollar-sign variables, which get mangled when copied. Everything below uses saved values instead.
2. The region changes per lab instance. Find it in the lab text, for example the `--location` line of the repository command.
3. The image build installs LibreOffice and takes 5–8 minutes. Wait for SUCCESS before deploying.
4. server.go is long, so it's split into two pastes. The lab's regex for swapping the file extension has a dollar sign in it. This version does the same job with Go's filepath.Ext, so the result is identical.
5. The binary is built with CGO_ENABLED=0 so it runs on any Debian base image. Without that, the container can crash with a "GLIBC not found" error if Cloud Shell's libraries are newer than the image's.
6. In a fresh lab, Cloud Storage's own service agent doesn't exist yet, so the lab's notification command fails with "service-...@gs-project-accounts... does not exist". Task 4 creates the agent first.
7. The checker lags. If a check shows 0 right after a successful step, wait 30–60 seconds and click again.

## Task 2 – Create the invoice microservice

Block 1 – server.go, part 1 (main and process):

```bash
cd ~/pet-theory/lab03
cat > server.go <<'EOF'
package main

import (
	"fmt"
	"log"
	"net/http"
	"os"
	"os/exec"
	"path/filepath"
	"strings"
)

func main() {
	http.HandleFunc("/", process)

	port := os.Getenv("PORT")
	if port == "" {
		port = "8080"
		log.Printf("Defaulting to port %s", port)
	}

	log.Printf("Listening on port %s", port)
	err := http.ListenAndServe(fmt.Sprintf(":%s", port), nil)
	log.Fatal(err)
}

func process(w http.ResponseWriter, r *http.Request) {
	log.Println("Serving request")

	if r.Method == "GET" {
		fmt.Fprintln(w, "Ready to process POST requests from Cloud Storage trigger")
		return
	}

	gcsInputFile, err1 := readBody(r)
	if err1 != nil {
		log.Printf("Error reading POST data: %v", err1)
		w.WriteHeader(http.StatusBadRequest)
		fmt.Fprintf(w, "Problem with POST data: %v \n", err1)
		return
	}

	localDir, err := os.MkdirTemp("", "")
	if err != nil {
		log.Printf("Error creating local temp dir: %v", err)
		w.WriteHeader(http.StatusInternalServerError)
		fmt.Fprintf(w, "Could not create a temp directory on server. \n")
		return
	}
	defer os.RemoveAll(localDir)

	localInputFile, err2 := download(gcsInputFile, localDir)
	if err2 != nil {
		log.Printf("Error downloading Cloud Storage file [%s] from bucket [%s]: %v",
			gcsInputFile.Name, gcsInputFile.Bucket, err2)
		w.WriteHeader(http.StatusInternalServerError)
		fmt.Fprintf(w, "Error downloading Cloud Storage file [%s] from bucket [%s]",
			gcsInputFile.Name, gcsInputFile.Bucket)
		return
	}

	localPDFFilePath, err3 := convertToPDF(localInputFile.Name(), localDir)
	if err3 != nil {
		log.Printf("Error converting to PDF: %v", err3)
		w.WriteHeader(http.StatusInternalServerError)
		fmt.Fprintf(w, "Error converting to PDF.")
		return
	}

	targetBucket := os.Getenv("PDF_BUCKET")
	err4 := upload(localPDFFilePath, targetBucket)
	if err4 != nil {
		log.Printf("Error uploading PDF file to bucket [%s]: %v", targetBucket, err4)
		w.WriteHeader(http.StatusInternalServerError)
		fmt.Fprintf(w, "Error downloading Cloud Storage file [%s] from bucket [%s]",
			gcsInputFile.Name, gcsInputFile.Bucket)
		return
	}

	err5 := deleteGCSFile(gcsInputFile.Bucket, gcsInputFile.Name)
	if err5 != nil {
		log.Printf("Error deleting file [%s] from bucket [%s]: %v", gcsInputFile.Name,
			gcsInputFile.Bucket, err5)
	}

	log.Println("Successfully produced PDF")
	fmt.Fprintln(w, "Successfully produced PDF")
}
EOF
grep -c "func " server.go
```

The count should be 2.

Block 2 – server.go, part 2 (convertToPDF), then build:

```bash
cd ~/pet-theory/lab03
cat >> server.go <<'EOF'

func convertToPDF(localFilePath string, localDir string) (resultFilePath string, err error) {
	log.Printf("Converting [%s] to PDF", localFilePath)
	cmd := exec.Command("libreoffice", "--headless", "--convert-to", "pdf",
		"--outdir", localDir,
		localFilePath)
	cmd.Stdout, cmd.Stderr = os.Stdout, os.Stderr
	log.Println(cmd)
	err = cmd.Run()
	if err != nil {
		return "", err
	}

	pdfFilePath := strings.TrimSuffix(localFilePath, filepath.Ext(localFilePath)) + ".pdf"
	log.Printf("Converted %s to %s", localFilePath, pdfFilePath)
	return pdfFilePath, nil
}
EOF
CGO_ENABLED=0 go build -o server
ls -la server
```

You should see the server binary listed with no errors.

## Task 3 – Create the PDF conversion service

Block 1 – Dockerfile, repository and image (5–8 minutes):

```bash
cd ~/pet-theory/lab03
cat > Dockerfile <<'EOF'
FROM amd64/debian
RUN apt-get update -y \
  && apt-get install -y libreoffice \
  && apt-get clean
WORKDIR /usr/src/app
COPY server .
CMD [ "./server" ]
EOF
gcloud artifacts repositories create pdf-converter --repository-format=docker --location=`cat ~/region`
gcloud builds submit --tag `cat ~/region`-docker.pkg.dev/`cat ~/project`/pdf-converter/pdf-converter
```

Wait for SUCCESS, then click Check my progress: Build an image with Cloud Build

Block 2 – deploy (private, 2 GB memory):

```bash
gcloud run deploy pdf-converter \
  --image `cat ~/region`-docker.pkg.dev/`cat ~/project`/pdf-converter/pdf-converter \
  --region `cat ~/region` --memory=2Gi --no-allow-unauthenticated \
  --set-env-vars PDF_BUCKET=`cat ~/project`-processed --max-instances=3
```

Check my progress: Deploy the PDF converter service

## Task 4 – Notification and service account

```bash
gcloud storage service-agent --project=`cat ~/project`
sleep 20
gcloud storage buckets notifications create --topic=new-doc --payload-format=json --event-types=OBJECT_FINALIZE gs://`cat ~/project`-upload
gcloud storage buckets notifications list gs://`cat ~/project`-upload
gcloud iam service-accounts create pubsub-cloud-run-invoker --display-name "PubSub Cloud Run Invoker"
gcloud run services add-iam-policy-binding pdf-converter \
  --member=serviceAccount:pubsub-cloud-run-invoker@`cat ~/project`.iam.gserviceaccount.com \
  --role=roles/run.invoker --region `cat ~/region`
```

If the service account create says it already exists, that's fine. The lab pre-creates it.

The notifications list must show topic new-doc. If the create failed with "service-...@gs-project-accounts... does not exist", wait 30 seconds and rerun the create and list lines. Without the notification, uploads never trigger the converter and the checks fail.

## Task 5 – Test the service is private

```bash
gcloud run services describe pdf-converter --region `cat ~/region` --format "value(status.url)" > ~/url
cat ~/url
curl -s -X GET `cat ~/url` | grep -o "Forbidden" | head -1
curl -s -X GET -H "Authorization: Bearer `gcloud auth print-identity-token`" `cat ~/url`
```

The anonymous call should print Forbidden. The authorized call should print "Ready to process POST requests from Cloud Storage trigger".

## Task 6 – Cloud Storage trigger

```bash

  --push-auth-service-account=pubsub-cloud-run-invoker@`cat ~/project`.iam.gserviceaccount.com
```
